# Bundle Builder

Frontend take-home implementation for the EcomExperts bundle-builder assignment.

## Prerequisites

- Node.js `^20.19.0` or `>=22.12.0`
- npm

The Phase 1 scaffold was verified locally with Node.js `25.6.1` and npm `11.9.0`.

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

## Current status

The Vite starter UI has been removed. The project retains React, TypeScript,
React Compiler, ESLint, Tailwind CSS v4, Vite, and npm. Product components and
the responsive bundle-builder interface will be added in the ordered phases
documented under `docs/`.
